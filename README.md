# Potluck

A block sandbox where everything is made by someone you know. Build, survive and play in a world of blocks, and look inside anything in it: every creature, block and mini game is a small Luau creation you can tweak, remix and share with a code.

The concept is idea 26 in [game-ideas](https://github.com/LinuxGroove/game-ideas/blob/main/ideas/26-potluck.md). The game is written in Rust on [Bevy](https://bevy.org/).
